Отзывы распределены по этапам пути гостя только при наличии соответствующей информации в тексте.

Отзывы по этапу

Три психографических портрета выделены по ценностям и болям, которые гости прямо описывают в отзывах. Портреты могут пересекаться: один отзыв способен отражать несколько мотивов выбора.

Модель Герцберга: мотиваторы создают дополнительную ценность и желание вернуться. Гигиенические факторы воспринимаются как обязательная норма, но при сбое вызывают недовольство.

Конкретные проблемы из отзывов 1–3★: оценки 1–2★ показывают критический опыт, 3★ — зоны, к которым стоит присмотреться.

Потерянный опыт

Выборка: полных отзывов, собранных локальным скрапером. Оценка пользователей рассчитана по звёздам выборки.
